# 我的小说设定

> 说明：用二级标题（##）区分卡片大类，三级标题（###）区分单张卡。
> 每张卡内部用「- 字段：值」列出信息，也可直接写散文，大模型会自动归纳。
> 支持的类型：人物 / 剧情 / 文风 / 伏笔 / 世界观。

## 人物卡

### 陆青崖
- 性别：男
- 外貌：青色长袍，眉间有一道旧疤
- 性格：沉稳、重情义，遇到不公会挺身而出
- 身份：青云宗外门弟子
- 能力：剑术初入门槛，体内封印未解

### 墨无尘
- 性别：男
- 外貌：一袭黑衣，看不清面容
- 性格：阴沉、城府极深
- 身份：神秘来客
- 能力：修为高深，手段狠辣
